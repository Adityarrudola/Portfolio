# Aditya Rudola — Portfolio

A personal portfolio website built with React to showcase my projects, skills, and experience in a clean and responsive format.

---

## 📌 Overview

This repository contains the source code for my personal portfolio. The goal of this project is to present my work and technical background in a simple, professional, and easy-to-navigate way while following modern frontend best practices.

---

## ✨ Features

- Clean and minimal UI
- Responsive design for all screen sizes
- Project showcase section
- Modular and reusable React components
- Optimized production build

---

## 🛠️ Tech Stack

- React  
- JavaScript (ES6+)  
- CSS  

---

## 🚀 Getting Started

Clone the repository:

git clone https://github.com/Adityarrudola/Portfolio.git  

Navigate to the project folder:

cd Portfolio  

Install dependencies:

npm install  

Start the development server:

npm run dev  

---

## 📦 Build

Generate an optimized production build:

npm run build  

The production-ready files are generated inside the `dist/` directory.

---

## 🌐 Deployment

This project can be deployed on modern static hosting platforms such as **Netlify**, **Vercel**, or **Cloudflare Pages**.
